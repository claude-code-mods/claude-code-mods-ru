# lcu-approve

> This English reference text was assembled from the upstream plugin manifest and catalogue metadata; the pinned upstream commit did not ship a README.

Per-app approval for computer use: allow this conversation, always allow, or deny, plus a panel of approved apps.

Native per-app approval for LCU computer use in the Claude app and Claude Code (Allow this conversation, Always allow, Deny), and the /computer-use-apps panel of approved apps.

## Install

```
/plugin install lcu-approve --marketplace claude-code-mods/claude-code-mods-ru
```

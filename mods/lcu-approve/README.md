# lcu-approve

> Этот справочный текст на английском языке составлен из манифеста плагина и метаданных каталога; в закреплённом коммите upstream README не поставлялся.

Разрешение на использование компьютера для каждого приложения: разрешить этот разговор, всегда разрешать или запрещать, а также панель с одобренными приложениями.

Встроенное разрешение на использование компьютера LCU для каждого приложения в приложении Claude и коде Claude (Разрешить этот разговор, Всегда разрешать, Запретить), а также панель /computer-use-apps с одобренными приложениями.

## Установка

```
/plugin install lcu-approve --marketplace claude-code-mods/claude-code-mods-ru
```

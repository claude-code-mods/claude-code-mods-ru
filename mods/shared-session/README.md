# shared-session

> This English reference text was assembled from the upstream plugin manifest and catalogue metadata; the pinned upstream commit did not ship a README.

Поделитесь сессией с помощью ссылки или с вашей командой; участники команды присоединяются, используя свой собственный код Claude, и наблюдают за каждым ходом в режиме реального времени.

Поделитесь сеансом Claude Code с помощью ссылки или со своей командой. Участники команды присоединяются со своего собственного кода Claude и общаются с ним: одна сессия выполняет работу, все видят каждый ход в реальном времени, а ведущий одобряет то, что выполняется на его компьютере. Войдите с помощью GitHub или Google для команд: живые сессии вашей команды, присоединяйтесь одним нажатием. Общий доступ осуществляется через общедоступный сервер этого проекта, если вы не настроите свой собственный (README: Конфиденциальность и общедоступный сервер).

## Установка

```
/plugin install shared-session --marketplace claude-code-mods/claude-code-mods-ru
```

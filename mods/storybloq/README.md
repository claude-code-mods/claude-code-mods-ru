Память проекта: тикеты, проблемы, передачи дел и уроки хранятся в папке .story/ в вашем репозитории.

Память проекта для кода и кодекса Claude. Storybloq хранит тикеты, проблемы, передачи дел и уроки в папке .story/ внутри вашего репозитория.

## Установка

```
/plugin install storybloq --marketplace claude-code-mods/claude-code-mods-ru
```

# turbo

> This English reference text was assembled from the upstream plugin manifest and catalogue metadata; the pinned upstream commit did not ship a README.

Фабрика программного обеспечения с искусственным интеллектом под контролем человека: вы решаете, что создавать, и оцениваете результат, а skills выполняет сборку и доставку.

Фабрика агентного программного обеспечения с контролем со стороны человека: вы решаете, что создавать, и оцениваете результат, а skills формирует, создает, дорабатывает и внедряет изменение, а также извлекает из него уроки.

## Установка

```
/plugin install turbo --marketplace claude-code-mods/claude-code-mods-ru
```
